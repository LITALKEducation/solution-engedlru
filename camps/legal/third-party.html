1. ภาพรวม

ระบบนี้ใช้บริการและซอฟต์แวร์ของบุคคลที่สาม แต่ละรายมีข้อกำหนดและนโยบายความเป็นส่วนตัวของตนเอง การใช้ระบบถือว่าคุณรับทราบว่าข้อมูลบางส่วนจะถูกส่งให้ผู้ให้บริการที่ระบุ เงื่อนไขของผู้ให้บริการอาจเปลี่ยนแปลงได้ โปรดตรวจสอบฉบับล่าสุดจากลิงก์ที่ให้ไว้ หากข้อความในหน้านี้ขัดกับเอกสารต้นฉบับของผู้ให้บริการ ให้ถือเอกสารต้นฉบับเป็นหลัก

ฟอนต์และสคริปต์ทั้งหมดโหลดจากเซิร์ฟเวอร์ของเราเอง ไม่มีการเรียก Google Fonts หรือ CDN ภายนอก จึงไม่ส่งที่อยู่ IP ของคุณให้บริษัทเหล่านั้น

2. ฟอนต์

Inter และ Noto Sans Thai

ใช้ทำอะไร: แสดงตัวอักษรภาษาอังกฤษ (Inter) และภาษาไทย (Noto Sans Thai) บนเว็บไซต์ ไฟล์ฟอนต์อยู่ในเซิร์ฟเวอร์ของเราเอง (/assets/fonts)

ข้อมูลที่เกี่ยวข้อง: ไม่มี เบราว์เซอร์ขอไฟล์จากเซิร์ฟเวอร์เราเท่านั้น

เงื่อนไขและนโยบาย: ทั้งสองเป็นฟอนต์แบบแปรผันที่เผยแพร่ภายใต้ SIL Open Font License 1.1 ซึ่งอนุญาตให้ใช้และแจกจ่ายได้ฟรี รวมถึงเชิงพาณิชย์ ไฟล์ที่ใช้มาจากแพ็กเกจ Fontsource ของโครงการเหล่านั้น ใบอนุญาตแนบไว้ในโฟลเดอร์เดียวกับไฟล์ฟอนต์ openfontlicense.org

Sarabun (ฟอนต์สำหรับสร้างไฟล์ PDF)

ใช้ทำอะไร: ฝังในไฟล์ PDF ที่ระบบสร้างในเบราว์เซอร์ (เช่น แผ่นรายชื่อ) ให้ภาษาไทยแสดงถูกต้อง

ข้อมูลที่เกี่ยวข้อง: ไม่มีข้อมูลผู้ใช้ส่งออกไปที่ใด

เงื่อนไขและนโยบาย: Sarabun ออกแบบโดย Cadson Demak เผยแพร่ภายใต้ SIL Open Font License 1.1 ไฟล์ที่ระบบใช้อาจเป็นฉบับที่จัดรูปแบบสำหรับ PDF ตามสัญญาอนุญาตดังกล่าว openfontlicense.org

3. การเข้าสู่ระบบ

Auth0 (Okta)

ใช้ทำอะไร: จัดการการเข้าสู่ระบบและเซสชัน ผ่านโดเมน auth.litalkeducation.com

ข้อมูลที่เกี่ยวข้อง: อีเมล ชื่อ รูปโปรไฟล์ สถานะยืนยันอีเมล เวลาเข้าสู่ระบบ และโทเค็นเซสชัน Auth0 ประมวลผลข้อมูลเหล่านี้ในฐานะผู้ให้บริการของผู้จัดค่าย

เงื่อนไขและนโยบาย: Auth0 เป็นผลิตภัณฑ์ของ Okta เอกสารทางกฎหมายของ Auth0 · นโยบายความเป็นส่วนตัวของ Okta

Google Account (ช่องทางเข้าสู่ระบบ)

ใช้ทำอะไร: ใช้บัญชี Google ของมหาวิทยาลัยยืนยันตัวตน นี่เป็นบริการเดียวของ Google ที่ระบบใช้

ข้อมูลที่เกี่ยวข้อง: ที่อยู่อีเมล ชื่อ และรูปโปรไฟล์จากบัญชีของคุณ (ขอเฉพาะข้อมูลพื้นฐาน) เมื่อคุณเข้าสู่ระบบ Google จะรู้ว่าคุณกำลังเข้าใช้ระบบนี้ผ่าน Auth0

เงื่อนไขและนโยบาย: การใช้บัญชี Google อยู่ภายใต้ข้อกำหนดและนโยบายของ Google ข้อกำหนดของ Google · นโยบายความเป็นส่วนตัวของ Google

4. โครงสร้างพื้นฐานและเว็บโฮสติ้ง

Cloudflare (Pages, Workers, D1, R2)

ใช้ทำอะไร: ให้บริการเว็บไซต์ API ฐานข้อมูล (D1) และพื้นที่เก็บไฟล์ เช่น รูปลายเสื้อและไฟล์แนบ (R2) รวมถึงเครือข่ายส่งเนื้อหาและป้องกันการโจมตี

ข้อมูลที่เกี่ยวข้อง: ข้อมูลทั้งหมดที่คุณกรอกในระบบถูกเก็บในบริการของ Cloudflare บันทึกการเข้าถึงทางเทคนิค (เช่น IP) ถูกประมวลผลโดย Cloudflare อาจมีการประมวลผลนอกประเทศไทย

เงื่อนไขและนโยบาย: เงื่อนไขการใช้บริการของ Cloudflare ข้อกำหนดเว็บไซต์ · ข้อตกลงการใช้บริการ · นโยบายความเป็นส่วนตัว

GitHub (และ GitHub Actions)

ใช้ทำอะไร: เก็บซอร์สโค้ดของระบบและ deploy ขึ้นเว็บอัตโนมัติ

ข้อมูลที่เกี่ยวข้อง: ไม่มีข้อมูลส่วนบุคคลของผู้ใช้ระบบถูกเก็บใน GitHub (เก็บเฉพาะโค้ดและค่าตั้งค่าที่ไม่ใช่ความลับ)

เงื่อนไขและนโยบาย: เงื่อนไขของ GitHub ข้อกำหนดการใช้บริการ · นโยบายความเป็นส่วนตัว

5. บริการตรวจภาพ AI

Sightengine (ตรวจภาพที่สร้างด้วย AI)

ใช้ทำอะไร: ช่วยตรวจว่ารูปลายเสื้อที่ส่งน่าจะสร้างด้วย AI หรือไม่ เป็นเครื่องมือช่วย การตัดสินขั้นสุดท้ายเป็นของผู้จัดค่าย และหากบริการไม่ตอบ ระบบจะไม่ปิดกั้นนักศึกษา (ดู นโยบายความเป็นส่วนตัว ข้อ 5)

ข้อมูลที่เกี่ยวข้อง: รูปลายเสื้อที่คุณอัปโหลดจะถูกส่งไปให้ Sightengine วิเคราะห์ และได้รับคะแนนความน่าจะเป็นกลับมา ระบบเก็บคะแนนและผลสรุปไว้ในฐานข้อมูลของเรา ไม่ส่งชื่อหรือข้อมูลส่วนตัวอื่นไปพร้อมรูป

เงื่อนไขและนโยบาย: โปรดดูข้อกำหนดและนโยบายความเป็นส่วนตัวฉบับล่าสุดที่เว็บไซต์ของผู้ให้บริการ sightengine.com

6. ซอฟต์แวร์โอเพนซอร์ส

ไลบรารีต่อไปนี้เก็บไว้ในเซิร์ฟเวอร์ของเราเอง (ไม่โหลดจาก CDN) แต่ละรายการเป็นไปตามสัญญาอนุญาตของผู้พัฒนา ไฟล์ใบอนุญาตแนบไว้ในโฟลเดอร์ /assets/vendor

ไลบรารีใช้ทำอะไรสัญญาอนุญาต

7. ฟีเจอร์ของเบราว์เซอร์และบริการแจ้งเตือน

  • กล้อง: ใช้สแกน QR ภาพถูกอ่านในเครื่อง ไม่อัปโหลด
  • ตำแหน่งที่ตั้ง: ใช้ตรวจว่าอยู่ในพื้นที่ลงทะเบียนเมื่อผู้จัดเปิดใช้ ระบบเก็บเพียงระยะห่างและความแม่นยำ ไม่เก็บพิกัดดิบ
  • การแจ้งเตือนผ่านเบราว์เซอร์ (Web Push) ในระบบงบประมาณ: หากคุณเปิดรับแจ้งเตือน ข้อมูลการสมัครรับแจ้งเตือนจะถูกส่งผ่านบริการ push ของผู้ผลิตเบราว์เซอร์ของคุณ (เช่น Google, Apple, Mozilla) ซึ่งมีนโยบายของตนเอง คุณปิดได้ในการตั้งค่าเบราว์เซอร์
