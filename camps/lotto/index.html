ระบบจัดการการจับสลาก

จัดการรายชื่อและหมายเลขสลาก ตรวจสอบสิทธิ์ด้วย QR Code และป้องกันการใช้สิทธิ์ซ้ำ

เข้าสู่ระบบผู้ดูแล / เจ้าหน้าที่

ใช้บัญชี Google มหาวิทยาลัยที่ได้รับสิทธิ์ camp_admin หรือ budget_admin

สแกน QR Code นักศึกษา

QR Code ต้องมีรหัสนักศึกษา 6–12 หลัก

เจ้าหน้าที่

กรอกรหัสด้วยตนเอง

รอการสแกน QR Code

จัดการรายชื่อและเลขจับสลาก

เลขจับสลากต้องไม่ซ้ำกันในชุดการจับสลากนี้

นำเข้ารายชื่อหลายคนด้วย CSV

รูปแบบ: รหัสนักศึกษา, ชื่อ-นามสกุล, เลขจับสลาก (มีหรือไม่มีหัวตารางก็ได้)

ตรวจสอบสถานะการใช้สิทธิ์

ค้นหาเพื่อดูว่าใครถูกตัดสิทธิ์แล้ว พร้อมเวลาที่สแกนและเจ้าหน้าที่
